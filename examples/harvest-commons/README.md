# Harvest Commons — an example platform design

A fictional cooperative that connects small farms around a city with the restaurants and households
that want to eat what grows nearby. The design walks through all three phases of the Platform
Design Toolkit: exploration (`1-exploration/`), strategy design (`2-design/`) and growth
(`3-growth/`).

```bash
pnpm pdt42 --dir examples/harvest-commons guide      # where the design stands
pnpm pdt42 --dir examples/harvest-commons validate   # consistency check
```
